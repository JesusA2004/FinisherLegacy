# Scan media — asset contract

Rendered by `resources/js/components/public/media/LegacyScanMedia.vue`,
used inside `LegacyCodePreview.vue`. If a real phone photo exists, it
replaces the CSS phone-scanning scene (mosaic QR + scan line) already built
there.

| Archivo | Estado | Qué debe mostrar |
|---|---|---|
| `scan-phone.webp` | FALTA ASSET | Mano sosteniendo un teléfono escaneando la placa/QR. |
| `scan-result.webp` | FALTA ASSET | Pantalla del teléfono mostrando el Legacy Profile ya abierto. |
| `legacy-scan.webm` / `.mp4` | opcional | Video corto del gesto de escaneo completo. |

Mínimo ~1600px de lado largo.
